# Adam Adkins | Design & Development

A minimal personal portfolio and independent creative studio website.

## Stack

Static HTML, CSS and vanilla JavaScript. Built to deploy directly to Cloudflare Pages without a build step.

## Local preview

Run a simple local server (for example, `python3 -m http.server 3000`) and open `http://localhost:3000`.

## Cloudflare Pages

Connect this repository to Cloudflare Pages. Set **Production branch** to `main`, **Build command** to *(empty)*, and **Build output directory** to `/` (repository root).
